## Basic WordPress plugin with Webpack

### Setup(don't clone)
- Download and Install it to your local WordPress installation
- Renaming the folder name(`aios-webpack-basic`) and `aios-webpack-basic.php` to your folder name with .php
- In the terminal, change into the plugin folder
- Run `npm install` to install the dependencies
- Run `npm run watch` to watch for file changes, or run `npm run build` to compile the changed files
